# 巫师 3: 狂猎

**英文**: The Witcher 3: Wild Hunt

## Pro Tips

- 按下 <kbd>F5</kbd> 可以快速存档.

## 关键选择

- **卢文伯爵的宝藏**: 选择选项二 "我为了宝藏而来".

## BOSS 战

### 尖叫怪

**任务**: 委托: 尖叫怪.

战斗技巧是通过高频率的输出使得尖叫怪再起不能.

战斗技巧是尽量站立于尖叫怪的侧后方 (尖叫怪的攻击范围是前方区域), 并通过不断的输出使其无法再次起飞.

操作正确的情况下应该是围绕着尖叫怪旋转并不断砍杀.

### 狼人尼伦

**任务**: 我心狂野.

二阶段可以移步到洞穴入口处脱战, 然后进行存档和冥想. 否则死亡后将从一阶段重新开始.

战斗技巧是使用**阿尔德法印**重置其行为, 然后找到规律进行闪避和攻击. 反复该过程即可不断输出, 快速击杀狼人.

操作正确的情况下应该可以将狼人一直围在角落不断砍杀.

此外, 据网友说法, 在玛格丽特试图阻止我们调查时可以先收下双倍报酬, 然后继续调查. 最终击杀狼人并获得猎人小屋里的箱子钥匙.
